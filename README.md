# Nombre de tu Proyecto / Marca

Sitio web desarrollado para mostrar una tienda de mates.

🔗 **Sitio desplegado en vivo:**  https://mateoresa.github.io/proyecto-coder-mrmates/

---

## 🚀 Tecnologías utilizadas

- **HTML5:** Estructura semántica en 5 páginas.
- **CSS3 / SCSS (Sass):** Estilos modulares organizados por carpetas (partials, variables, mixins).
- **Bootstrap 5:** Componentes responsivos (Navbar, Carousel, Grillas).
- **Git & GitHub:** Control de versiones y despliegue continuo con GitHub Pages.

---

## 📁 Estructura del proyecto

```text
proyecto/
├── css/
│   └── styles.css          # CSS compilado
├── scss/
│   ├── utilities/          # Variables y mixins
│   ├── base/               # Reset y tipografía
│   ├── layout/             # Header, Nav y Footer
│   └── components/         # Botones, Cards, Carousel
├── img/                    # Recursos visuales y multimedia
├── pages/                  # Vistas secundarias (nosotros, productos, contacto, etc.)
├── index.html              # Página principal
└── README.md               # Documentación del proyecto
